# 材料驱动的工商企业信用模型升级说明

## 1. 结论

五份材料共同支持把当前“若干维度直接加权”的模型升级为四层决策链：

1. 原始数据层：工商、股权、经营、三年财务、司法税务、内部订单/应收/逾期及行业数据。
2. 子模型层：业务风险、财务风险、外部信用、交易行为分别计算；每个子模型保留指标公式、权重、缺失状态和贡献。
3. 决策层：业务风险与财务风险先通过矩阵形成基础信用锚点，再叠加外部信用与交易行为；准入规则可以一票否决或累计调分。
4. 策略层：评分与等级不直接等于授信额度。建议额度同时受申请额度、交易规模、回款能力、现有暴露、数据完整度和强规则上限约束，随后映射授信期与监控频率。

## 2. 材料提炼

| 材料 | 可落地内容 | 本项目用法 |
| --- | --- | --- |
| 标准信用报告 | 企业事实、三年财务、风险扫描、外部 49.58/C 基准 | 建立原始企业样本；外部结果只作对照标签 |
| 一般工商企业评级 | 业务/财务分层、三级权重、阈值、三年 20/30/50 加权、矩阵映射 | 建立透明专家评分卡及跨期特征 |
| 投资风险模型方案 | 内外部数据目录、准入/评价/监控三模型、AHP、一致性检验、KS/AUC | 建立数据治理、强规则和模型验证要求 |
| 标普工商企业方法论解读 | 行业风险×竞争地位、现金流/杠杆、评级基准、支持与调整因素 | 建立非线性业务/财务锚点与调整层 |
| 信控项目会议纪要 | ERP 订单、应收逾期、行业分模、国内外场景、额度/账期输出 | 增加交易行为子模型及额度策略 |

## 3. 拟实施的运算关系

### 3.1 跨期指标

三年均有值：

`跨期值 = 20% × Y-2 + 30% × Y-1 + 50% × Y`

仅两年有值：

`跨期值 = 30% × Y-1 + 70% × Y`

每个派生字段必须保存原值、单位、期间、公式、来源和计算版本。

### 3.2 子模型

- 业务风险：行业风险、企业规模、竞争地位、经营效率、收入与利润趋势、客户/产品集中度。
- 财务风险：盈利能力、资产质量、资本结构、短期偿债、长期偿债、现金流与杠杆。
- 外部信用：主体状态、司法执行、失信、税务、行政处罚、股权冻结、关联风险与支持能力。
- 交易行为：订单规模、履约、发票匹配、应收账款、逾期、回款周期、额度使用和坏账。

指标分先在组内运算：

`指标组得分 = Σ(指标标准分 × 组内权重) / Σ(可用指标权重)`

同时单独计算完整度，不把缺失值伪装成零风险：

`完整度 = Σ(可用指标权重) / Σ(全部指标权重)`

关键字段缺失会触发人工复核及额度上限，而不是简单扣成坏客户。

### 3.3 业务—财务锚点

业务风险和财务风险分别映射为 1—6 档，再查询 6×6 矩阵得到基础信用锚点。这样可以体现相同财务杠杆在不同业务质量下产生不同信用结果，避免线性加权掩盖短板。

### 3.4 调整与策略

`最终评分 = clamp(基础信用锚点 + 外部信用调整 + 交易行为调整 + 风险规则调整, 0, 100)`

重大风险规则直接输出 NR/禁入；高风险和中风险可以累计扣分，并分别设置累计上限。额度建议采用最小约束原则：

`建议额度 = min(申请额度上限, 交易规模上限, 回款能力上限, 模型等级上限, 强规则上限, 数据完整度上限)`

## 4. 英纳法样本的数据边界

已确认：主体、股权、经营、专利资质、行业、司法概况、2021—2023 年资产负债与利润数据、财务比率、风险规则命中和外部评级。

未确认：现金流量表、有息债务、EBITDA、利息支出、应收账款明细、内部订单、ERP 回款与逾期、申请额度。上述字段在原始数据中保持 `null`，模型需要给出“数据待补充”和置信度，不得按 0 处理。

## 5. 模型治理要求

- 专家权重使用 AHP 时，保存判断矩阵并要求一致性比率 `CR < 0.1`。
- 有足够标签样本后，以停止经营、违约或坏账等明确目标校准；上线前至少检查 KS、AUC、稳定性和分档坏样本率单调性。
- 每次模型运行保存输入快照、派生特征、模型版本、规则版本、完整度、计算链和人工调整原因。
- 外部报告的评级口径与平台内部评级口径可能不同，回放时只比较排序、策略和风险方向，不强行拟合单个外部结论。
